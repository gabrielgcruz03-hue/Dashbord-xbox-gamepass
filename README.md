# Dashbord-xbox-gamepass
 Este projeto apresenta um dashboard interativo em Excel para análise das assinaturas do Xbox Game Pass, EA Play e Minecraft Season Pass. Os dados simulados de 2024 permitem visualizar métricas de vendas por tipo de plano, comparativos entre produtos e indicadores de desempenho, com filtros dinâmicos e gráficos intuitivos.
