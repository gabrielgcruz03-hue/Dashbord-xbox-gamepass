# Xbox Game Pass Dashboard

Este projeto apresenta um **dashboard interativo em Excel** desenvolvido como parte do desafio "Criando um Dashboard de Vendas do Xbox" da DIO.

## 🎯 Objetivo
O objetivo é analisar as assinaturas do **Xbox Game Pass**, **EA Play Season Pass** e **Minecraft Season Pass**, permitindo visualizar o desempenho das vendas por tipo de assinatura (Anual, Mensal e Trimestral).

## 📊 Dados Utilizados
Os dados foram fornecidos pela plataforma DIO e representam valores simulados de vendas e assinaturas durante o período de **01/01/2024 a 31/12/2024**.

Principais métricas:
- Total de assinaturas por tipo de plano
- Comparativo entre EA Play e Minecraft Season Pass
- Total de assinaturas do Xbox Game Pass

## 🧩 Ferramentas Utilizadas
- **Microsoft Excel** (versão 365)
- **Gráficos dinâmicos**
- **Segmentação de dados**
- **Formatação condicional**
- **Funções de agregação (SOMASE, CONT.SE, etc.)**

## 🚀 Instruções para Reprodução
1. Baixe o arquivo `dashboard_xbox_game_pass.xlsx`.
2. Abra no Excel (recomenda-se versão 365 ou superior).
3. Utilize os botões de segmentação para filtrar os dados por tipo de assinatura.
4. Explore os gráficos e indicadores para entender o desempenho das vendas.
